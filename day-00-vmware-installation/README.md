# Day 00 — Install VMware Workstation

[Back to course](../README.md) · [Next: Download Rocky Linux](../day-01-download-rocky/README.md)

## Goal
Install the hypervisor that will run our Linux practice machine.

## Before you start
Use a supported Windows host with administrator access and hardware virtualization enabled.
Our teaching baseline is an 8 GB RAM host; 16 GB or more offers more room for later labs.
A 500 GB host drive is a course planning recommendation, not a Rocky Linux minimum.
Check free space as well as total drive capacity.

## Understand the words

- **Host:** your physical computer and its operating system.
- **Guest:** the operating system running inside a virtual machine.
- **Hypervisor:** software that creates and runs virtual machines.
- **VMware Workstation:** the desktop hypervisor used in this series.

## Walkthrough

1. Follow the official [VMware desktop hypervisor download guidance](https://knowledge.broadcom.com/external/article/368734/download-and-license-vmware-desktop-hyperv.html).
2. Download the Windows installer appropriate for your supported host.
3. Run it and follow its prompts. Restart if requested.
4. Open VMware Workstation and confirm the application starts.

Download screens and account requirements can change; use the current official instructions.

## Your practice task
Open VMware Workstation and explain the difference between the host and guest in your own words.
