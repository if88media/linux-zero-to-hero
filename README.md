Welcome! Learn Linux step by step with simple commands,

## 🎯 Who Is This For?

Beginners, aspiring Linux administrators, and anyone
building a foundation for DevOps.

No previous Linux experience is required. Start with
Day 00 and practice alongside the videos.

## 💻 Your Practice Environment

- VMware Workstation
- Rocky Linux 10 virtual machine
- A terminal and a willingness to practice!

## 🚀 What You Will Learn

- Navigate Linux and explore your system
- Work with files and directories
- Manage users, groups, permissions, and ownership
- Manage processes, services, and storage
- Install and configure Apache and MariaDB
- Troubleshoot CPU, memory, disk, and network issues
- Understand networking, firewalld, and SELinux
- Get started with Bash automation
